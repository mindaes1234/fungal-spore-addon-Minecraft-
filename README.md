# Fungal Spore Addon

This repository now includes a basic Bedrock addon scaffold for the custom fungal entities.

Entity IDs created:
- `spore:baio`
- `spore:drowned`
- `spore:human`
- `spore:husk`
- `spore:griefer`

Files are under the `addon/` directory and are ready for import into a Minecraft Bedrock addon project.

Notes:
- The JSON files use the `.bbmodel` names as the entity ID base.
- You can export the model geometry from each BBModel and rename the files to match the entity names if needed.
- Example geometry names are already referenced as:
  - `geometry.spore_baio`
  - `geometry.spore_drowned`
  - `geometry.spore_human`
  - `geometry.spore_husk`
  - `geometry.spore_griefer`
